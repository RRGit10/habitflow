# HabitFlow

HabitFlow is a mobile app built with Expo and React Native.

## Get Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npx expo start
   ```

3. Open the app using Expo Go, an iOS simulator, or an Android emulator.

## Development

Edit the files inside the `app` directory to develop your application. This project uses Expo Router for file-based navigation.
